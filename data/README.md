# Data

The original sequencing data and reference files used in this analysis are not included in this repository because they were provided as part of a University of Glasgow coursework assessment and are not available for redistribution.

The analysis used:

- Raw FASTQ sequencing reads

- Mus musculus mm10 chromosome 2 reference/index files

- A chromosome 2 GTF annotation

- Gene- and transcript-level count matrices

The analysis scripts in bash/ and R/ document the computational workflow used to process and analyse these data.
