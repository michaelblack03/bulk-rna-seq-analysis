# Tools Used in Pipeline
## Languages & Computing
- Bash: pipeline development and workflow automation
- R: statistical analysis, exploratory data analysis and visualisation
- PBS: HPC job scheduling

## RNA-seq Processing
- Scythe: adapter trimming
- Sickle: read quality and length filtering
- HISAT2: RNA-seq read alignment
- SAMtools: SAM/BAM conversion and processing
- StringTie: transcript assembly and expression quantification
- prepDE.py: generation of gene- and transcript-level count matrices

## Statistical Analysis & Visualisation
- DESeq2: differential expression analysis and count-data modelling
- limma: batch-effect investigation and correction
- ashr: log2 fold-change shrinkage
- vsn: mean-SD analysis
- svglite: SVG figure export
- RColorBrewer: colour palettes for visualisation
- genefilter: expression filtering/statistical utilities
